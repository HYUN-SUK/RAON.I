# Action-to-Tag Mapping Dict (행동-태그 매핑 정의서)

라온아이의 '스마트 캠핑 플랜'과 개인화 추천을 구동하기 위한 핵심 기반인 **'사용자 페르소나 추출 로직'**의 설계 규칙과 매핑 사전을 정의하는 문서입니다.

이 문서는 스마트 캠핑 플랜 엔진(`smartPlan.ts`) 구현 완료 후, 실제 사용자 데이터를 연동하기 위한 Phase 2 작업의 **단일 진실 공급원(SSOT)** 역할을 합니다.

---

## 🎯 1. 아키텍처 원칙 (Philosophy)

- **Event-Triggered Tagging**: 사용자의 모든 행동(화면 스크롤 등)을 무의미하게 감시하지 않습니다. 결제, 찜하기, 글작성 등 '의도가 명확한 명시적 행동(Strong Signal)'만을 추출하여 태그 점수로 환산합니다.
- **Controlled Vocabulary (통제된 어휘 풀)**: AI의 할루시네이션을 막고 데이터의 밀도를 높이기 위해, 앱 전체의 취향을 표현하는 마스터 태그 풀을 초기 **50개 내외로 엄격히 고정**합니다.
- **Time-Decay (시간 감가상각)**: 사용자의 취향 변화를 반영하기 위해, 오래된 행동으로 얻은 태그 점수는 서서히 감소하고 최근 행동일수록 높은 가중치를 받습니다.

---

## 🧩 2. 마스터 태그 풀 기반 (Master Tag Pool - 30선 초안)

시스템 DB(`user_personas` 테이블)에 컬럼 또는 JSON 키 형태로 고정될 1차 마스터 태그 카테고리입니다.

1.  **동반자 (Who)**: `#나홀로(솔캠) #커플/부부 #우정캠 #영유아동반 #초등동반 #청소년동반 #반려견동반 #다인가족`
2.  **캠핑 스타일 (How)**: `#미니멀리즘 #맥시멀/장비러 #차박/오토캠 #백패킹/와일드 #장박선호 #당일치기(캠프닉)`
3.  **환경 선호도 (Where)**: `#조용한숲속 #물놀이계곡 #오션뷰(바다) #탁트인들판 #별보기명소 #도심근교`
4.  **활동 성향 (Activity)**: `#휴식/낮잠 #요리/먹방 #불멍매니아 #액티비티(도보/산책) #로컬투어(관광) #인생샷(포토)`
5.  **가치관/특성 (Value)**: `#가성비중시 #프리미엄(돈안아낌) #위생결벽(화장실중요) #에코캠퍼(LNT)`

---

## 🗺️ 3. 행동-태그 매핑 사전 (Mapping Dictionary Draft)

앱 내의 특정 기능(Trigger Point)과 그 기능이 실행되었을 때 부여되는 마스터 태그 점수 규칙입니다. (상세 내역은 구현 시 고도화됩니다.)

### 3.1 예약 보드 (Reservation) - 가장 높은 가중치
- **평일(일~목) 예약 결제 완료**: `[#휴식/낮잠 +5]`, `[#조용한숲속 +3]`
- **연속 2박 이상 예약 완료**: `[#장박선호 +5]`, `[#요리/먹방 +3]`
- **전기 미사용/노지 사이트 예약**: `[#와일드캠퍼 +5]`, `[#장비보유 +3]`, `[#미니멀 +2]`

### 3.2 활동 보드 (My Space & Community)
- **우천 캠핑 리뷰 작성 (해시태그 사용)**: `[#와일드캠퍼 +5]`
- **사진 3장 이상 첨부 기록 작성**: `[#인생샷(포토) +5]`, `[#맥시멀/감성 +2]`
- **[요리/레시피] 관련 게시글 '좋아요'**: `[#요리/먹방 +4]`
- **[지역 행사/축제] 게시글 '스크랩/저장'**: `[#로컬투어(관광) +5]`, `[#액티비티 +3]`

### 3.3 스마트 플랜 피드백 (Interactive Slots)
- **추천된 '대형 마트' ➔ '동네 하나로마트' 교체**: `[#로컬투어 +4]`, `[#가성비 +2]`
- **추천된 '노포 식당' ➔ '프랜차이즈/깔끔한 식당' 교체**: `[#위생결벽 +5]`
- **추천된 '유료 박물관' ➔ '무료 산책로' 교체**: `[#액티비티(도보) +5]`, `[#자연친화 +5]`

### 3.4 라이프스타일 미션 (Gamification)
- **텐트 피칭 타임어택 성공 인증**: `[#숙련자/고인물 +5]`, `[#효율중시 +3]`
- **LNT(쓰레기 줍기) 미션 참여**: `[#에코캠퍼(LNT) +5]`

## 🛠️ 4. 시스템 구현 로드맵 (Phase 2)

이 매뉴얼을 기반으로 한 구현은 다음 순서로 진행됩니다. (스마트 캠핑 플랜 엔진 구축 완료 후 시작)

1.  **DB Schema**: `user_personas` 테이블 생성 (유저별 마스터 태그 점수 및 갱신일자 기록)
2.  **Logic Core**: `src/lib/persona.ts` 내부에 행동 상수와 점수를 매핑하는 `ACTION_TAG_MAP` Dictionary 구현 및 Decay 수학 모델(반감기) 작성.
3.  **App Triggers**: 커뮤니티(추천, 북마크), 예약(결제 완료), 플랜 카드 교체 등 프론트엔드 핵심 기능 컴포넌트에 태그 업데이트 함수 연동.
4.  **Engine Integration**: 완성된 `persona.ts`를 `smartPlan.ts` 엔진에 주입하여 진짜 유저 데이터를 통한 AI 추천 가동.

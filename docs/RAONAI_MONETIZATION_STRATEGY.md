# 라온아이(RAON.I) 수익화 전략 기획 보고서 (Finalized: 스마트플랜 LIVE)

> **문서 목적**: RAONAI 앱의 핵심 기능인 '스마트플랜'을 바탕으로, 1인 개발 환경에서 실현 가능하며 사용자의 명확한 결제 유인(Willingness to Pay)을 끌어낼 수 있는 **'실시간 동적 대처(Live Adaptation)' 중심의 유료화 패키지** 전략을 확정함.

---

## 1. 수익화 핵심 전략: "공간적 제안(Map)" vs "시간적 동행(Live Timeline)"

사용자에게 무료 제공되는 기본 기능과 유료 제공되는 프리미엄 기능의 근본적인 구조(UI/UX) 차이를 두어 압도적인 결제 명분을 확보합니다.

### 1.1 무료 티어 (스마트플랜 Basic) : 카테고리 기반 공간적 제안
*   **개념**: 여행 전 캠핑장과 페르소나를 기반으로 생성되는 훌륭한 **'사전 가이드북(Map)'**.
*   **형태**: 시간 순서가 아닌 카테고리별 제안 (가는 길, 오는 길, 캠핑장 근처 맛집/명소/마트 등).
*   **특징**: 유저가 리스트를 보고 스스로 일정을 조립해야 하며, 상황 변경 시 수동으로 장소를 스왑(Swap)함.

### 1.2 유료 티어 (스마트플랜 LIVE 패키지) : 초밀착 시간대별 타임라인
*   **개념**: 2박 3일 전체 일정을 시간 단위로 분 단위까지 조율해 주는 **'동적인 내비게이터(GPS)'**.
*   **형태**: 집에서 출발하는 순간부터 복귀까지, 아침/점심/저녁 단위의 완벽한 **시간대별 세부 타임라인 UI** 제공.
*   **특징 (The "Start" Button)**: 각 일정 카드마다 **[출발/시작] 버튼**이 존재함. 버튼을 누르는 순간 실시간 대처 기능(핏스탑, 스위처 등)이 활성화되어 현장 상황에 맞춘 맞춤형 내비게이팅이 시작됨.
*   **모드 분리 (캠핑 vs 일반 여행)**: 캠핑(텐트 피칭, 바비큐 준비, 불멍 등 체류 시간 위주)과 일반 여행(명소 간 잦은 이동 위주)의 특성을 분리하여 AI가 각기 다른 패턴의 타임라인을 생성.

## 2. 스마트플랜 LIVE: 5대 핵심 유료 기능 (Core Features)

'시간대별 타임라인'이라는 거대한 판 위에, 현장의 변수를 방어하는 5가지 Live 기능이 얹어집니다.

### ① 타임 리밸런싱 (Dynamic Time-Shifter) - *타임라인의 핵심*
*   **기능**: 시간대별 일정에서 유저가 특정 장소에 오래 머물거나 지연될 경우, 타임라인을 아래로 드래그(또는 지연 버튼 클릭)하면 AI가 남은 2박 3일 일정 전체의 예상 시간과 동선을 즉시 재계산 및 재정렬.

### ② 스마트 핏스탑 (Smart Pitstop / 경유지 삽입)
*   **기능**: 타임라인 이동 중 갑자기 약국, 커피, 충전소가 필요할 때, 현재 경로를 이탈하지 않는 선에서 최적지를 찾아 타임라인 사이에 즉각 끼워 넣음.

### ③ 원탭 테마 스위처 & 트래픽 디톡스 (One-Tap Context Switch & Detour)
*   **기능**: 타임라인 진행 중 폭우나 체력 고갈 시, "실내 대피", "칠링 모드" 버튼을 누르면 당일 남은 타임라인 전체를 해당 조건에 맞게 한 번에 전면 재구성. 교통 정체 시 뷰 카페 등으로 우회.

### ④ SOS 메디컬 레이더 (Live Medical SOS)
*   **기능**: 언제든 SOS 버튼을 누르면, 현재 타임라인과 무관하게 내 GPS 기준 "지금 영업 중이 확실한" 심야 약국/응급실을 필터링하여 최단 거리 동선 제공.

### ⑤ Co-Op 플래너 (가족/일행 실시간 조율기)
*   **상황**: 일정에 대해 일행 간 호불호가 갈리거나 의견을 하나로 모으기 힘들 때.
*   **기능**: AI가 생성한 타임라인에서 일행을 초대함. 일행들은 각 시간대별 일정의 **'대체 리스트'**를 열어 인당 최대 3개까지 '좋아요' 투표 가능. 투표 합산 1위 장소가 타임라인의 메인 카드로 자동 갱신되며, 장소명 옆에 그룹만 볼 수 있는 득표수 뱃지가 노출됨.

## 3. 결제 모델 (Pricing Strategy)

사용자의 캠핑/여행 빈도에 맞춘 유연한 결제 시스템 도입.
1.  **1회성 패스 (One-Time Pass)**: 이번 여행 한 번만 Live 기능을 쓰고 싶은 라이트 유저용 (예: 1,900원).
2.  **다회권 (Multi-Pass)**: 5회권, 10회권 묶음 할인 판매. 한 시즌에 여러 번 다니는 캠퍼용 (예: 5회 7,900원).
3.  **구독형 (Subscription)**: 무제한 Live 생성, 우선 예약권 등 추가 혜택이 포함된 헤비 유저용 정기 결제 (예: 월 3,900원).

# 📜 라온아이 명소 추천 알고리즘 고도화 사양서 (Option C 계층형 통합)

> **문서 버전**: v1.0.0  
> **작성일**: 2026-08-11

## 1. 개요 및 변경 배경

기존 명소 추천 알고리즘에서는 Master DB의 `trust_score` 수집 편차로 인해, 전국구 대표 랜드마크 명소(예: `예당호 출렁다리`)가 1/2티어 뱃지 수집 누락 시 기본 점수 `50점`으로 저장되어 10km 이상 떨어진 소형 생가/기념관(`85점`)에 밀리는 억울한 하강 현상이 존재했습니다.

이를 해결하기 위해 **맛보기 엔진에 검증된 방안 C 알고리즘(Layer 1)**을 **기존 정밀 스마트플랜 추천 엔진에도 100% 동일하게 이식**하여 랜드마크 우대 및 인접 핫플레이스 최우선 상위 노출을 보장하고자 합니다.

---

## 2. 계층형 통합 알고리즘 (Layered Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│ [Layer 2] 정밀 플랜 전용 맥락 레이어 (출발 당일 기동 - 기존 기능 보존)     │
│  + 우천/폭설 시 실내 장소(박물관/미술관 등) +20점 가점                     │
│  + 아이/반려동물/시니어 동반자 페르소나 딥매칭 점수 (cFit)                  │
├────────────────────────────────────────────────────────────────────────┤
│ [Layer 1] 방안 C 표준 베이스 엔진 (맛보기 & 정밀 공통 100% 이식)           │
│  + Math.max(trust_score, 80) (랜드마크 50점 억울함 하한선 구제)          │
│  + Math.min(base_pop * 0.5, 40) (TMap/KTO 실측 인기도 가점, Cap 40점)     │
│  + 화이트리스트 가점 (+40점)                                           │
│  + 5km 이내 초근접 가점 (+20점)                                         │
│  + 전구간 거리 감점 (-2.0점/km)                                         │
│  + 동일 명칭 및 1km 이내 근접 중복 도려내기 (Deduplication)               │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 세부 스코어링 수식 정의

$$\begin{aligned}
\text{최종 점수 (trustScore)} &= \text{Math.max(trust\_score, 80)} \quad \text{(랜드마크 키워드 매칭 시 하한선 보정)} \\
&+ \text{Math.min(base\_pop \times 0.5, 40)} \quad \text{(TMap/KTO 실측 인기도 가점, 최대 40점)} \\
&+ \text{화이트리스트 가점 (+40점)} \\
&+ \text{초근접 가점 (+20점, 5km 이내)} \\
&- \text{거리 감점 (직주거리 km \times 2.0)} \\
&+ \text{Layer 2 맥락 가점 (우천 실내가점 +20점 / 페르소나 cFit)}
\end{aligned}$$

### 🎯 랜드마크 타겟 키워드 (화이트리스트 패밀리)
> `출렁다리`, `스카이워크`, `전망대`, `케이블카`, `루프탑`, `수목원`, `식물원`, `둘레길`, `바다길`, `해수욕장`, `계곡`, `폭포`, `레일바이크`, `자연휴양림`, `휴게소`, `생가`, `기념관`, `미술관`, `박물관`, `문학관`, `정원`, `방조제`, `등대`

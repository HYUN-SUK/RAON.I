## 🎯 배경 재확인

**캠장님 상황:**
1. 대형 예약플랫폼의 과도한 수수료로부터 **독립**
2. 소규모 캠핑장의 수익한계 → **추가 수익원 필요**
3. 플랫폼 유지/발전을 위해 수익화 **필수**

**문제:**
- "고급 편집 기능"만으로는 **지갑을 열 가치 부족**
- 무료 편집기가 이미 많음 (Canva 등)

### 카테고리 A: 기록의 물리적 가치화 📚

#### 1. 포토북 인쇄 & 배송 (핵심!)

```
┌──────────────────────────────────────┐
│  📖 나의 캠핑 포토북                 │
│  ────────────────────────────────── │
│  2025년 우리 가족 캠핑 이야기        │
│                                      │
│  [미리보기] → [인쇄 주문]            │
│                                      │
│  💰 1권 19,900원 (20페이지)          │
│     추가 페이지당 +500원             │
│     배송비 3,000원                   │
└──────────────────────────────────────┘
```

**왜 돈을 낼까?**
- 디지털 기록 → **실물 책**으로 소장
- 가족에게 선물, 거실 장식
- 시즌별/연도별 자동 구성

**수익 모델:**
- 인쇄 대행 마진 30~40%
- 평균 단가 19,900원 → 마진 ~6,000원

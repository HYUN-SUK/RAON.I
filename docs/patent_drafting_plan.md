# 라온아이 스마트 캠핑/관광 플랜 임시명세서(가명세서) 출원자료 작성계획서

본 문서는 상용 코드 수준의 무료 버전 Core 6대 기술과 비즈니스 수익화를 위한 프로 버전(Pro Version) 5대 유료 킬러 기능들을 결합하여, 출시 전 신속한 우선권 선점을 위한 임시명세서(가명세서)의 구조적 작성 가이드라인 및 계획을 정의한 문서입니다.

---

## 1. 가명세서 작성 가이드라인 및 용어 규격화

임시명세서 작성 시 논리적 일관성과 심사 편의성을 극대화하기 위해 다음의 4대 표준 용어를 엄격히 준수하여 설명서를 기술합니다.

1.  **사용자 단말기 (User Terminal)**: 사용자 인터페이스(UI), 단말기 내장 가속도/자이로 센서 수집, 온디바이스 일출/일몰 삼각함수 연산, 초고주파 출력 및 딥링크 경로 인계를 수행하는 장치.
2.  **서비스 제공 서버 (Service Provider Server)**: Supabase DB 관리, 공공데이터/로컬 API 쿼터 제어형 백그라운드 폴링 및 동기화, 다단계 캐싱 스케줄러 및 RAG 전처리를 수행하는 시스템.
3.  **하이브리드 여정 설계 엔진 (Hybrid Itinerary Design Engine)**: 서비스 제공 서버 및 사용자 단말기 상에 분산 배포되어, 선적재 캐싱(Track A)과 실시간 경로 연산(Track B) 및 1차 물리 룰 엔진을 융합하는 제어 모듈.
4.  **캠핑 안전 환경 관리 모듈 (Camping Safety Module)**: 기상 예측 정보 매핑, 단말 센서 가속도 임계 검증, 주파수 합성 및 실시간 웹소켓(Supabase Realtime) 이중 통신 경보를 수행하는 모듈.

## 2. 임시명세서 출원자료 상세 작성 계획 (템플릿 기준)

---

### 📋 발명의 명칭
*   **명칭**: "멱등적 장소 데이터 정규화 및 단말기 센서 융합에 기반한 AI 적응형 여정 설계 및 온디바이스 실시간 캠핑 환경 제어 시스템 및 방법"
    *(System and Method for AI-Based Adaptive Itinerary Design and On-Device Real-Time Camping Environment Control Based on Idempotent Place Data Normalization and User Terminal Sensor Fusion)*

---

### 📋 기존 기술의 문제점
1.  **AI 여정 설계의 시간/공간적 오류 및 API 비용**: 
    기존 AI 플래너들은 유휴 LLM(대형 언어 모델)의 환각으로 폐업 장소를 권고하거나, 지리적 연산의 부재로 물리적으로 도달 불가능한 일정을 생성함. 사용자가 여정을 수정할 때마다 고비용의 LLM 호출이 반복되어 서버 유지 비용이 폭증함.
2.  **체류형 야외 캠핑 환경에서의 현장 안전 및 피칭 제어 기술 부재**:
    캠핑은 한 장소에 장시간 머무는 **체류형 여정**으로 정적 일정표 제공만으로는 유료화 가치가 떨어짐. 캠퍼들은 현장 피칭 시 해와 바람의 방향 분석 오류로 텐트가 붕괴되거나, 돌풍 폴대 파손, 오지 도난/야생동물 침입, 사계절 독충/해충 등 실시간 현장 위험 상황에 대해 적절한 기술적 방어를 제공받지 못함.

---

### 📋 본 발명의 핵심 해결 수단

본 발명은 무료 버전의 데이터 정제/캐싱/라우팅 기술(1~6)과 프로 버전의 하이브리드 연산 및 단말기 센서 연계(7~11)를 결합하여 문제를 해결함.

#### [무료 버전의 6대 해결 수단]
1.  **Quota Optimization (일일 지역 순환 동기화)**: 전국 17개 권역을 17일 주기로 분할하여 매일 1개 도/시씩 마스터 POI의 유효성과 변경점을 백그라운드 정기 갱신하여 API 차단을 원천 예방함.
2.  **Context-Aware Scoring (누적 인증 및 안전 융합)**: 백년가게, LX인증맛집 등 다중 소스 인증 데이터를 누적 가산하고, 국립중앙의료원(NMC) API의 실시간 가용 병상/장비 수를 스코어링에 동적 융합함.
3.  **Double-Timing Cache & Quota (이중 시점 사전 캐싱 및 카테고리별 차등 쿼터제)**: 
    *   **사용자 예약 기준 반경 설정**: 사용자가 예약한 캠핑장의 지리적 좌표(또는 20km Geo-Cluster 중심)를 기준으로 30km 반경을 지정하여 캐싱을 수행함.
    *   **1차 조기 적재 (예약 다음 날 새벽)**: 신규 예약 완료 다음 날 새벽에 배치 캐싱을 구동하여 주변 정적 장소(식당, 마트, 명소) 캐싱 정보를 DB에 조기 선적재.
    *   **2차 정밀 동적 갱신 (예약 3일 전)**: 실제 투숙 3일 전(D-3)에 실시간 기상 예보, 실시간 최저가 등유 유가, 안전 가용 병원 응급병상 수 등 변동성이 높은 환경 데이터를 재수집 및 갱신해 랭킹 최종 보정.
    *   **카테고리별 쿼터제**: 수집 시 카테고리별 호출 한도(음식점 1000개, 마트/명소/병원 등은 각 100개 이하의 Limit)를 강제 부여하여 병렬 비동기(`Promise.all`)로 캐시 DB에 벌크 적재함.
4.  **Idempotent Normalize (2단계 교차 멱등화)**: 주소의 광역 지자체명(SIDO) 표준화 및 기호/괄호 정보 제거를 통해 결정론적 UUID v5를 발급(1차)하고, 실시간 엔진 런타임에서 `name_cleanAddr` 키 매핑 기반의 2차 중복 제거와 소스 병합을 수행함.
5.  **Spiral Search (나선형 주소 힐링)**: 동절기 등유 수급을 위해 5~30km 나선형 확장 루프를 실행하며, 오피넷 TM128 좌표를 WGS84로 변환 후 카카오 API 역지오코딩의 3중 폴백으로 주소를 복원함.
6.  **Adaptive Routing (Alternatives Tree & OS 딥링크)**: AI 서사 일관성을 유지하면서 교체 가능한 Alternatives 장소 트리(14개 후보)를 최초 1회 JSON에 포함해 전송하고, OS 기기(Android vs iOS)에 맞춘 딥링크 매개변수 분기 및 출발지 생략형 실시간 GPS 길찾기를 개시함.

#### [프로(Pro) 버전의 5대 해결 수단 (신규 탑재)]
7.  **RAG-Rule Hybrid Engine (관광 Pro - RAG 기반 타임테이블)**:
    챗GPT 등의 환각을 차단하기 위해 멱등 정규화 마스터 DB(Ground Truth)를 LLM 컨텍스트(RAG)로 제공함. 특히 LLM 비용 절감을 위해, 일정을 변경 시마다 LLM을 호출하지 않고, **1차 물리적 룰 엔진**이 두 좌표 간의 실제 물리 거리(Haversine) 및 이동 시간을 연산하여 스케줄 뼈대를 먼저 구성한 뒤 최종 사용자 나레이션 설명 서술만 LLM에 넘기는 원가 통제식 하이브리드 연산 제공.
8.  **On-Device Sun & Wind Pitching Compass (캠핑 Pro 1 - 피칭 나침반)**:
    외부 천체 API 호출 비용 및 네트워크 차단 상황을 방어하기 위해, 단말기의 실시간 GPS 위경도와 날짜를 기반으로 일출, 남중, 일몰의 방위각과 고도를 모바일 단말 단에서 오프라인 수학적(SunCalc 알고리즘)으로 실시간 계산함.
    전체 일정 슬라이더 조절 시 예보 풍향/풍속 벡터를 3D 나침반 상에 다중 반투명 화살표의 회전 및 크기로 가시화하며, 오픈소스 지형도(Leaflet + OpenStreetMap) 모달로 무료 연계함.
9.  **Live Wind Safety (캠핑 Pro 2 - 윈드 세이프티)**:
    15분 간격 기상청 풍속 및 순간풍속 API를 추적하여 돌풍(풍속 6m/s, 순간풍속 10m/s 이상) 감지 시 사용자 단말기에 긴급 알림을 발송함. 텐트 골조 구조(돔, 리빙쉘, 타프)와 캠핑장 바닥 마감재(데크, 파쇄석, 마사토 등)의 인장 계수 매핑 알고리즘을 수행하여 바람 침하 방향에 대응하는 펙(Peg)/스트링(String) 물리 결속 및 보강 가이드를 제공함.
10. **Live Tent Sentry (캠핑 Pro 3 - 텐트 보안관)**:
    단말기의 DeviceMotionEvent(3축 가속도계, 자이로스코프) 및 마이크 정보 수집. 오작동을 필터링하기 위해 바람 흔들림 및 일반 캠핑장 소음을 측정하는 **5초 영점 조절(Calibration)**을 먼저 실행하고, 영점 대비 충격 변화량($\Delta G > 0.15G$)이 0.3초 이상 지속 시 침입 판정함.
    1차 로컬 대응(초고주파 16kHz~18kHz 경보 및 카메라 LED 점멸) 및 2차 웹소켓(Supabase Realtime) 채널을 통한 일행 단말기로의 실시간 푸시 경보 전송.
11. **Live Pest & Insect Guard (캠핑 Pro 4 - 독충/해충 가드)**:
    기온, 습도, 해당 사이트 산림 형태 및 질병관리청 살인진드기 활성 예측 공식을 융합하여 독충 지수를 도출함. 모기 및 해충이 기피하는 천적 잠자리의 날갯짓 음파 대역(16kHz~18kHz)을 단말기 오디오 단에서 주파수 합성(Frequency Synthesis) 송출하여 해충 장벽을 형성하고, 물리적 벌레 물림에 대한 쯔쯔가무시 식별 가이드를 제공함.

### 📋 단계별 데이터 흐름 (Flow)

```
[Step 1: 데이터 수집 및 정규화 (1차 멱등화)]
   - daily-region-sync.mjs 가동 ➔ 지자체 순환 갱신 ➔ 주소 정규화 및 UUID v5 마스터 DB 벌크 적재

[Step 2: 예약 트리거 2단계 시차 사전 캐싱 (Track A)]
   - (1차 캐싱) 신규 예약 다음 날 새벽 ➔ Geo-Clustering 기반 20km 반경 내 주변 데이터 DB 선적재
   - (2차 캐싱) 체크인 3일 전(D-3) ➔ 실시간 기상 예보, 실시간 최저가 등유 유가, 안전 병원 등 동적 데이터 2차 캐싱 갱신
   - (캐싱 쿼터) 수집 시 카테고리별 차등 Quota(음식점 1000, 마트/명소/의료/주유소 각 100) 부여하여 병렬 적재

[Step 3: 실시간 여정 결합 및 2차 멱등화 (Track B)]
   - 사용자 플랜 요청 ➔ 캐싱 DB 조회 ➔ name_cleanAddr & allSources 배열 기반 실시간 2차 중복 제거
   - LBS 목적지/출발지 좌표 ➔ 카카오 API 기반 중간지점 도로망 정밀 산출

[Step 4: 하이브리드 점수 산출 및 RAG 전처리]
   - 기상청 날씨 + 페르소나 센서 수집 ➔ ContextFit 연산 (우천 가점 + 소아과/반려견/보양식 안전 가산)
   - 백년가게, LX인증 누적 합산 스코어링 + NMC 실시간 가용 병상 정보 가중치 융합
   - 1차 물리적 룰 엔진 이동 스케줄 뼈대 갱신 ➔ Alternatives 장소 목록 묶음 JSON 구성

[Step 5: 여정 도중 실시간 노드 변경 및 시간-거리 재계산]
   - 여정 도중 실시간 장소 검색 및 추가/삭제 요청 ➔ 1차 물리적 룰 엔진 기동
   - Haversine 거리 및 이동 시간 실시간 재계산 ➔ 일정 가용 시간 압축 및 전체 타임라인 오프셋 Shift
   - 물리적 이동 가능 여부 판단(Constraint Guard) ➔ 통과 시에만 LLM 최종 수정 서사 합성

[Step 6: 단말기 센서 융합 및 실시간 환경 제어 (Pro 기능)]
   - SunCalc 오프라인 연산 + 0-72시간 풍향 벡터 나침반 가시화
   - DeviceMotionEvent 3축 데이터 스트리밍 ➔ 5초 영점 필터 ➔ \Delta G 임계값 비교 침입 탐지
   - 쯔쯔가무시 활성 지수 연산 및 16~18kHz 초고주파 해충 퇴치 음파 연속 출력

[Step 7: 길찾기 인계 및 안전 대피]
   - 내비게이션 요청 ➔ iOS/Android 단말 OS 감지 ➔ goalx/y 분기 변수 매핑 ➔ sp 출발지 생략 딥링크 실행
```

### 📋 기대되는 기술적 효과 (Technical Effects)
1.  **서버 트래픽 과부하 방지 및 비용 절감**:
    1차 물리적 룰 엔진 선검증을 통해 일정 수정에 따른 무작위적인 LLM API 호출을 50% 이상 절감하여 토큰 원가 부담 최소화.
2.  **네트워크 비가용 지역에서의 생존 가용성 보장**:
    일출/일몰 각도 계산 및 해충 기피 주파수 송출을 외부 API나 서버 통신 없이 단말기의 온디바이스(On-device) 수학식 연산으로 100% 실행하여 음영 지역에서의 배터리 보존 및 생존율 제고.
3.  **도난/침입 방지 장치의 오보율 획기적 개선**:
    바람에 흔들리는 텐트의 물리적 불규칙 진동(노이즈)을 5초 간의 기저 대역 노이즈 캔슬링(영점 조절)을 통해 걸러내어, 센서 작동의 신뢰도를 극대화.
4.  **데이터 공급망의 내결함성 확보**:
    API 주소 결측 발생 시 3중 역지오코딩 폴백 체인과 TM128 좌표계 실시간 맵 투사를 수행하여, 전국 단위 장소 매칭 및 AI 타임라인 생성의 에러 발생률을 0%에 가깝게 방어.
